MAGICC6 parameter values
========================

land_c4mip_bern.csv holds the land carbon-cycle parameters of SCM4OPT's "MAGICC6 defaults"
mode (used when no --cm6mdl calibration is selected). The values are taken from the
configuration files distributed with the compiled MAGICC6 executable
(MAGTUNE_C4MIP_BERN.CFG, MAGCFG_DEFAULTALL_69.CFG; columns magicc6_name, magicc6_file).
